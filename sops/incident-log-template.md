# Incident log

Copy this block into the day's field note under a `## Incident` heading.
Fill it in within 15 minutes of the event.

```
Time (local):
Robot / system:
People present:
What happened (facts only, one paragraph):
Immediate action taken:
Damage or injury (state "none" explicitly):
Data affected:
Suspected cause (mark as hypothesis):
Follow-up owner and deadline:
```

Rules: report every near miss. Facts first, causes later. Never edit the
original entry, append corrections below it.
