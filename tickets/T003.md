# Deterministic clock and event scheduler

Implement a fixed-step simulation clock and deterministic event queue for camera exposure, perception delivery, encoder samples, controller ticks, and cutter events.

## Acceptance

- Identical seed and inputs produce identical event order.
- Events at the same timestamp use a documented stable priority.
- No domain code calls the wall clock.
- Long runs do not accumulate avoidable floating-point step drift.
- Tests cover phase offsets, delayed delivery, cancellation, and reset.
