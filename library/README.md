# Library

How to add an entry:

1. Copy the front matter block below. Fill every field.
2. Papers: `library/papers/<first-author>-<year>-<short-slug>.md`.
3. Topics and tools: `library/<kind>/<slug>.md`.
4. Every factual claim gets a link or a "(from field, unverified)" tag.
5. Set `status: reviewed` only after a second read.

```yaml
---
title:
date:
tags: []
status: draft
source:     # URL, DOI, or "field"
---
```

Paper entries use these sections: **Problem**, **Core idea**, **Result that
matters**, **What it changes in practice**, **Open questions**.
